# 账单处理工具

把原来两个脚本（数据清洗 `清洗代码.py` + 正式处理 `formal_billing_processing_v5_fixed.py`）
合并整理为函数，并封装成一个带界面的工具：**选择 Excel → 填写月份 → 填写燃油费率 → 一键生成结果**。

## 重要说明：关于 exe 文件

我这边是 Linux 环境，**无法直接生成 Windows 的 .exe 文件**（PyInstaller 只能在目标系统上打包）。
所以这次交付的是：**完整、已测试通过的源代码 + 一键打包脚本**，您只需要在 **Windows 电脑**上
双击运行一次 `build_exe.bat`，1-2 分钟就能自动生成 `账单处理工具.exe`，之后就是普通的双击运行了，
不需要再懂任何代码。

## 文件清单

| 文件 | 说明 |
|---|---|
| `billing_core.py` | 核心处理逻辑（清洗 + 正式处理），已用模拟数据完整测试通过 |

## 打包步骤（只需做一次）

1. 确认 Windows 电脑上装有 Python（没有的话去 [python.org](https://www.python.org/downloads/) 下载安装，
   安装时务必勾选 **"Add python.exe to PATH"**）。
2. 把上面 5 个文件放在**同一个文件夹**里。
3. 双击 `build_exe.bat`，等待自动安装依赖、自动打包（会弹出黑色命令行窗口，属于正常现象）。
4. 打包成功后，文件夹里会出现 **`账单处理工具.exe`**，以后直接双击这个文件使用即可，
   不再需要 Python 环境、不再需要这几个 .py 文件（可以整体转移到别的电脑上单独使用这一个 exe）。

## 使用方法（打包完成后）

双击 `账单处理工具.exe`，界面从上到下：

1. **第一步：选择原始账单Excel文件** —— 点"浏览..."选择要处理的账单文件。
2. **第二步：填写处理参数**
   - **账单月份**：格式 `YYYY-MM`，例如 `2026-06`（决定按哪个月筛选【仓租】【出库订单】数据）
   - **燃油费率**：支持 `18.5%`、`18.5`、`0.185` 几种写法
     - 默认应用到本月覆盖的所有自然周（统一费率）
     - 如果需要**按自然周分别设置不同费率**，勾选下方的"按自然周分别设置燃油费率"。
       点击"一键生成结果"后，程序会先自动完成清洗、算出本月实际覆盖到的自然周，
       然后弹窗让您逐周填写费率（会用上面填的费率作为每周默认值，只需改动不一样的那几周即可）
   - **系统中订单件数**（可选）：填了就会自动与清洗后【出库订单】的总数据量核对，不一致时会弹窗询问是否仍要继续
3. **高级选项**（一般不用改）：汇总函数默认 `SUM`；未知 sheet（除仓租/入库详情/出库订单/工单/索赔抵扣/核账补收/退件订单/退款详情之外的其他 sheet）默认"自动识别"最可能的费用列进行汇总，也可以改成"逐个询问"（遇到有歧义的多候选列时会弹窗让你选）或"全部跳过"。
4. **第三步：输出文件** —— 默认自动保存在原文件同目录下（文件名后加"_已处理"），也可以点"另存为"自己指定。
5. 点 **"一键生成结果"**，下方日志区会实时显示每一步的处理情况，处理完成会弹窗提示，并可以点"打开输出文件夹"直接查看结果。

## 处理逻辑（和原两份脚本保持一致）

**第一阶段（清洗）**
1. 按填写的月份筛选【仓租】（按"时间"列）、【出库订单】（按"创建时间"列），月份外的数据剔除并留档到 `_月份外已删除` sheet
2. 整行完全一致的重复记录去重，保留首条，被删除的记录留档到 `_重复数据` sheet
3. 剔除【出库订单】AI列（订单处理费）为空或为0的记录，留档到 `_AI列为空已删除` sheet
4.（可选）与"系统中订单件数"核对，不一致会提示是否继续

**第二阶段（正式处理）**
1. 【仓租】汇总 R 列「实际费用」；【入库详情】汇总 K 列「费用」
2. 【出库订单】按填写的燃油费率写入 AZ（实际燃油费）/AL（物流费用）/AY（费用总计）公式并求和
3. 【工单】【索赔抵扣】【核账补收】【退件订单】【退款详情】按固定规则汇总；其余未知 sheet 按关键词自动识别费用列汇总
4. 生成/更新「汇总」sheet：前六行不变，第七行起链接各 sheet 的费用总值，最后一行是费用总计（黄色高亮）

## 关于按周燃油费率

原 `formal_billing_processing_v5_fixed.py` 支持按**自然周分别输入不同的燃油费率**（逐周询问）。
这版工具默认是"填一个费率、应用到全月"，勾选"按自然周分别设置燃油费率"后即可恢复按周填写：
程序会先自动清洗数据、算出本月实际覆盖到的自然周（一般是 4-5 周，跨月首尾周也会算进来），
一次性弹窗列出所有周，逐周填写即可，不需要像原脚本那样一个个命令行输入。

## 常见问题

- **打包时报错找不到 Python** → 重新安装 Python 并勾选 "Add to PATH"，或者安装后重启电脑再试。
- **打包时依赖安装失败** → 检查网络连接（需要能访问 pypi.org），或联系 IT 帮忙配置好网络代理后再试。
- **exe 打开后一闪而过 / 打不开** → 大概率是杀毒软件误拦截，添加信任或关闭实时防护后重新生成。
- **提示某个 sheet 或表头找不到** → 说明表格结构有变化，日志里会写清楚具体是哪个 sheet 缺了哪个表头，按提示核对原始 Excel 结构即可。
