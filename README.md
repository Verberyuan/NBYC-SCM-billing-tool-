# 账单处理工具

本工具将原有的两个账单处理脚本：

* 数据清洗脚本：`清洗代码.py`
* 正式处理脚本：`formal_billing_processing_v5_fixed.py`

重新整理为模块化函数，并封装为带图形界面的桌面工具。

用户只需完成以下操作，即可生成处理结果：

> **选择原始 Excel 文件 → 填写账单月份 → 设置燃油费率 → 一键生成结果**

整个处理过程均通过图形界面完成，无需手动运行 Python 脚本或输入命令。

---

## 一、关于 Windows EXE 文件

PyInstaller 通常需要在目标操作系统中执行打包，因此本次交付内容包括：

* 完整的工具源代码
* 已完成验证的核心处理逻辑
* Python 依赖清单
* Windows 一键打包脚本

在 Windows 电脑上双击运行 `build_exe.bat`，脚本会自动安装所需依赖并生成：

```text
账单处理工具.exe
```

打包通常只需几分钟。生成完成后，可直接双击 EXE 文件运行工具，无需再手动启动 Python 脚本。

---

## 二、文件清单

| 文件                 | 说明                         |
| ------------------ | -------------------------- |
| `billing_core.py`  | 核心业务处理模块，包含数据清洗及正式账单处理逻辑   |

## 三、打包方法

打包操作仅需执行一次。

### 1. 安装 Python

请先确认 Windows 电脑已安装 Python。

如尚未安装，可前往 [Python 官方网站](https://www.python.org/downloads/) 下载并安装。

安装时请务必勾选：

```text
Add python.exe to PATH
```

否则打包脚本可能无法识别 Python 环境。

### 2. 准备打包文件

请将以下文件放在同一个文件夹中：

```text
billing_core.py
billing_tool.py
requirements.txt
build_exe.bat
README.md
```

### 3. 执行一键打包

双击运行：

```text
build_exe.bat
```

脚本将自动完成以下操作：

1. 检查 Python 环境；
2. 安装程序依赖；
3. 安装或调用 PyInstaller；
4. 打包生成 Windows EXE 文件。

运行过程中会出现命令行窗口，这是正常现象，请勿提前关闭。

### 4. 获取 EXE 文件

打包成功后，文件夹中会生成：

```text
账单处理工具.exe
```

之后可直接双击该文件使用。

通常情况下，运行 EXE 文件不再需要安装 Python，也不需要同时保留原始 `.py` 文件。需要在其他 Windows 电脑上使用时，可将生成的 EXE 文件复制到目标电脑。

> 建议妥善保留源代码及打包文件，以便后续业务规则调整或重新打包。

## 四、使用方法

双击运行：

```text
账单处理工具.exe
```

按照界面中的步骤依次完成配置。

### 第一步：选择原始账单文件

点击“浏览...”按钮，选择需要处理的 Excel 账单文件。

建议在处理前保留原始文件备份。工具默认不会直接覆盖原始文件。

---

### 第二步：填写处理参数

#### 1. 账单月份

填写格式为：

```text
YYYY-MM
```

例如：

```text
2026-06
```

该参数用于筛选以下工作表中的数据：

* `仓租`：根据“时间”列筛选；
* `出库订单`：根据“创建时间”列筛选。

不属于所选月份的数据将从正式处理数据中移除，并单独保存至留档工作表。

---

#### 2. 燃油费率

支持以下格式：

```text
18.5%
18.5
0.185
```

以上三种写法均表示燃油费率为 `18.5%`。

默认情况下，填写的费率会统一应用于所选月份覆盖的全部自然周。

如不同自然周需要使用不同的燃油费率，请勾选：

```text
按自然周分别设置燃油费率
```

勾选后，程序将在数据清洗完成后：

1. 自动识别当前月份实际覆盖的自然周；
2. 弹出按周费率设置窗口；
3. 使用主界面填写的燃油费率作为各周默认值；
4. 允许用户单独修改费率不同的自然周。

通常每个月会覆盖 4～5 个自然周，月初或月末涉及的跨月自然周也会被纳入计算。

---

#### 3. 系统中订单件数（可选）

可填写业务系统中显示的订单件数。

填写后，程序会将该数值与清洗后的 `出库订单` 数据总量进行核对。

如两者不一致，程序会弹出提示，由用户确认是否继续处理。

该参数仅用于数据核对，不填写不会影响其他处理流程。

---

### 高级选项

高级选项通常无需修改。

#### 汇总函数

默认使用：

```text
SUM
```

用于生成相关费用汇总公式。

#### 未知工作表处理方式

除以下标准工作表之外的其他工作表，均视为未知工作表：

* `仓租`
* `入库详情`
* `出库订单`
* `工单`
* `索赔抵扣`
* `核账补收`
* `退件订单`
* `退款详情`

未知工作表支持以下处理方式：

| 处理方式 | 说明                     |
| ---- | ---------------------- |
| 自动识别 | 根据表头关键词判断最可能的费用列，并自动汇总 |
| 逐个询问 | 当存在多个可能的费用列时，弹窗由用户选择   |
| 全部跳过 | 不处理未知工作表，也不将其加入费用汇总    |

默认设置为“自动识别”。

---

### 第三步：设置输出文件

默认情况下，处理结果会保存在原始文件所在目录，文件名自动增加：

```text
_已处理
```

例如：

```text
原始账单.xlsx
原始账单_已处理.xlsx
```

也可以点击“另存为”，自行指定输出路径及文件名。

---

### 开始处理

完成参数设置后，点击：

```text
一键生成结果
```

程序将依次执行数据清洗、费用计算和汇总表生成。

处理过程中，下方日志区域会实时显示：

* 当前处理步骤；
* 数据筛选情况；
* 删除及留档数量；
* 工作表汇总结果；
* 异常提示；
* 输出文件保存位置。

处理完成后，程序会弹出提示。可点击“打开输出文件夹”直接查看生成的结果文件。

## 五、处理逻辑

工具的处理规则与原有两份脚本保持一致，整体分为两个阶段。

---

### 第一阶段：数据清洗

#### 1. 按月份筛选数据

根据用户填写的账单月份筛选：

* `仓租`工作表：按“时间”列筛选；
* `出库订单`工作表：按“创建时间”列筛选。

不属于所选月份的数据将从正式数据中移除，并保存至：

```text
_月份外已删除
```

留档工作表中。

#### 2. 删除完全重复的数据

对整行内容完全一致的记录进行去重：

* 保留首次出现的记录；
* 删除后续重复记录；
* 将被删除的重复数据保存至：

```text
_重复数据
```

留档工作表中。

#### 3. 清理订单处理费无效的数据

检查 `出库订单` 工作表的 AI 列，即“订单处理费”列。

以下记录将被移除：

* AI 列为空；
* AI 列数值为 `0`。

被移除的数据将保存至：

```text
_AI列为空已删除
```

留档工作表中。

#### 4. 核对订单件数

如用户填写了“系统中订单件数”，程序会将其与清洗后的 `出库订单` 记录数进行比较。

如数量不一致，程序会提示差异，并由用户确认是否继续处理。

---

### 第二阶段：正式账单处理

#### 1. 仓租费用

对 `仓租` 工作表的 R 列“实际费用”进行汇总。

#### 2. 入库费用

对 `入库详情` 工作表的 K 列“费用”进行汇总。

#### 3. 出库订单费用

根据用户设置的燃油费率，对 `出库订单` 工作表写入并计算以下字段：

| 列  | 字段    | 说明            |
| -- | ----- | ------------- |
| AZ | 实际燃油费 | 根据对应订单及燃油费率计算 |
| AL | 物流费用  | 按原业务规则生成或更新   |
| AY | 费用总计  | 汇总订单相关费用      |

完成公式写入后，程序会对相关费用列进行求和。

当启用“按自然周分别设置燃油费率”时，不同自然周的订单将分别应用对应费率。

#### 4. 其他标准工作表

以下工作表按照既定业务规则进行费用汇总：

* `工单`
* `索赔抵扣`
* `核账补收`
* `退件订单`
* `退款详情`

#### 5. 未知工作表

对于非标准工作表，程序会根据高级选项进行处理：

* 自动识别最可能的费用列；
* 在存在歧义时询问用户；
* 或直接跳过。

自动识别主要依据表头中的费用相关关键词。

#### 6. 生成或更新汇总表

程序会生成或更新：

```text
汇总
```

工作表。

处理规则如下：

1. 保留汇总表前六行原有内容；
2. 从第七行开始，依次链接各工作表的费用汇总值；
3. 在最后一行生成全部费用的总计；
4. 对费用总计行进行黄色高亮显示。

## 六、按自然周设置燃油费率

原脚本 `formal_billing_processing_v5_fixed.py` 支持按自然周分别输入燃油费率，但需要通过命令行逐周填写。

新版工具保留了该功能，并改为图形界面集中设置。

启用方式：

```text
勾选“按自然周分别设置燃油费率”
```

点击“一键生成结果”后，程序会先完成数据清洗，再根据清洗后的订单日期自动计算实际涉及的自然周。

随后，程序会一次性显示全部自然周及对应费率输入框。

主界面填写的燃油费率将作为每个自然周的默认值。用户只需修改费率不同的周，无需逐项重复输入相同费率。

## 七、常见问题

### 1. 打包时提示找不到 Python

可能原因：

* 尚未安装 Python；
* 安装 Python 时未添加到系统 PATH；
* 安装完成后命令行环境尚未刷新。

解决方法：

1. 重新安装 Python；
2. 安装时勾选“Add python.exe to PATH”；
3. 安装完成后重新启动电脑；
4. 再次运行 `build_exe.bat`。

---

### 2. 打包时依赖安装失败

打包过程中需要从 Python 软件源下载依赖。

请检查：

* 当前电脑是否可以正常访问互联网；
* 是否可以访问 `pypi.org`；
* 公司网络是否限制 Python 软件源；
* 是否需要配置代理或由 IT 部门协助安装依赖。

网络恢复后，可重新运行 `build_exe.bat`。

---

### 3. EXE 文件无法打开或启动后立即关闭

常见原因包括：

* 杀毒软件或 Windows 安全中心误拦截；
* EXE 文件未完整生成；
* 打包过程中出现错误；
* 程序依赖未被正确打包。

建议：

1. 查看杀毒软件或 Windows 安全中心的拦截记录；
2. 确认文件来源可信后，将程序目录加入信任列表；
3. 删除未完整生成的文件并重新打包；
4. 保留打包窗口中的错误信息，以便进一步排查。

不建议在未确认安全策略的情况下长期关闭系统防护功能。

---

### 4. 提示找不到某个工作表或表头

该提示通常表示原始 Excel 文件结构发生了变化，例如：

* 工作表名称被修改；
* 必要工作表被删除；
* 表头名称发生变化；
* 表头所在行发生变化；
* 原有列被移动、删除或合并。

程序日志中会记录具体缺失的工作表或字段名称。

请根据日志提示核对原始 Excel 的工作表名称及表头结构。

---

### 5. 处理结果与预期不一致

建议重点检查：

* 账单月份是否填写正确；
* 燃油费率格式是否正确；
* 是否误启用了按周费率；
* 各自然周费率是否填写正确；
* 原始文件中是否存在合并单元格、隐藏行或异常公式；
* 原始工作表名称及表头是否符合预期；
* 日志中是否存在跳过、警告或识别失败的信息。

为便于排查，请保留：

* 原始 Excel 文件；
* 处理后的 Excel 文件；
* 程序日志内容；
* 使用的月份及燃油费率参数。

---

## 八、使用建议

* 首次使用时，建议先使用一份账单副本进行测试；
* 每次处理前保留原始文件，避免因人工操作覆盖原始数据；
* 不要在程序运行期间打开或修改正在处理的 Excel 文件；
* 处理完成后，建议抽查订单数量、燃油费、物流费及汇总金额；
* 如原始 Excel 模板结构发生变化，应先确认程序规则是否需要同步调整；
* 建议保留源代码、依赖文件及打包脚本，以便后续升级和维护。
