# 账单处理工具 v4.0.0

基于大榕树 SCM 格式 Excel 的多客户账单处理与核对工具，支持主账单与补充账单合并、账期判断、燃油费率匹配、费用重算、异常检测及审计结果输出。

本版本已使用五位客户的 **2026 年 7 月真实账单数据**完成端到端核对、回归测试和实际运行验证，已覆盖：

- 平台快递、自有快递、卡派自提等不同物流形式；
- 有燃油费率与无燃油费率客户；
- 主文件与补充文件合并；
- 跨月订单判断；
- 复合订单与多 SKU 明细；
- 手工费用、入库费、仓租费、询价打单等费用项目；
- 燃油费率边界、逐单取整及异常收费检查；
- 系统账单原值、可见明细和程序重算结果三方比对。

五位客户的七月账单均已完成逐单核验并成功跑通，相关问题已纳入程序的数据质量检查、异常报告及回归测试。
  注意：只有【卡派自提】按完成时间归属，平台/自有快递的 1970 完成时间不影响计算。
- **「金额列出现文本」** → 金额单元格混进了文字，改成纯数字或留空。
- **重算结果和平台账单对不上** → 打开「无法解释费用」逐单看差额来源，
  多数是费率周边界日（见交付说明中的"周一 vs 周二"问题）和跨月订单剔除造成的。
